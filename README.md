# Faccio io 0.3

Prima base Android dell'app **Faccio io**.

## Funzioni presenti
- schermata principale
- inserimento rapido attività
- elenco attività giornaliere
- completamento attività con checkbox
- workflow GitHub Actions per generare un APK debug

## Build
Il workflow `Build Android APK` crea `app-debug.apk` e lo pubblica come artifact GitHub Actions.
